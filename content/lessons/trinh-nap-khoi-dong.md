> Cần **máy ảo hoặc VPS**. Sửa sai cấu hình GRUB có thể làm máy không khởi động được. Hãy làm trên máy ảo, và chép bản dự phòng trước khi sửa.

## GRUB làm gì

Nhắc lại [bài 21](/bai/khoi-dong-he-thong): firmware (BIOS/UEFI) → **GRUB** → kernel + initramfs → systemd. GRUB 2 (**GR**and **U**nified **B**ootloader):

- Hiện menu chọn hệ điều hành / phiên bản kernel / chế độ khôi phục.
- Đọc kernel và initramfs từ `/boot` vào RAM.
- Truyền **tham số kernel** (ổ gốc ở đâu, chế độ nào…).

Máy khởi động BIOS hay UEFI:

```bash
[ -d /sys/firmware/efi ] && echo UEFI || echo BIOS
```

| | BIOS + GPT | UEFI |
|---|---|---|
| Phần lõi GRUB nằm ở | Phân vùng nhỏ "BIOS boot" (máy ảo trong bài: `vda14`, 4 MB) | File `.efi` trong phân vùng EFI, gắn ở `/boot/efi` |
| Xem / sửa mục khởi động của firmware | Không có | `efibootmgr` |

## Các file trong /boot

```bash
ls -l /boot
```

```text
-rw------- 1 root root  9144857 Sep 24 09:03 System.map-6.8.0-147-generic
-rw-r--r-- 1 root root   287601 Sep 24 09:03 config-6.8.0-147-generic
drwx------ 3 root root      512 Jan  1  1970 efi
drwxr-xr-x 6 root root     4096 Oct 17 12:58 grub
lrwxrwxrwx 1 root root       28 Oct 17 12:56 initrd.img -> initrd.img-6.8.0-147-generic
-rw-r--r-- 1 root root 30707872 Oct 17 12:57 initrd.img-6.8.0-147-generic
lrwxrwxrwx 1 root root       25 Oct 17 12:56 vmlinuz -> vmlinuz-6.8.0-147-generic
-rw------- 1 root root 15083912 Sep 24 10:28 vmlinuz-6.8.0-147-generic
...
```

| File | Là gì |
|---|---|
| `vmlinuz-<phiên bản>` | Kernel (đã nén) |
| `initrd.img-<phiên bản>` | initramfs: hệ thống file nhỏ chứa driver để gắn ổ gốc. Tạo lại bằng `sudo update-initramfs -u` |
| `config-<phiên bản>` | Cấu hình đã dùng khi biên dịch kernel |
| `System.map-<phiên bản>` | Bảng địa chỉ các hàm trong kernel (dùng khi gỡ lỗi) |
| `vmlinuz`, `initrd.img` | Symlink tới bản mới nhất. `.old` là bản trước |
| `grub/` | Cấu hình và module của GRUB, trong đó có `grub.cfg` |
| `efi/` | Điểm gắn phân vùng EFI |

Mỗi lần cập nhật kernel (qua `apt upgrade`), một cặp `vmlinuz`/`initrd.img` mới được thêm vào, và GRUB tự được cập nhật để khởi động bản mới. Bản cũ vẫn giữ lại để quay về nếu bản mới lỗi.

## Cấu hình GRUB: /etc/default/grub

`/boot/grub/grub.cfg` là file GRUB đọc lúc khởi động, nhưng nó được **sinh tự động**:

```bash
sudo head -6 /boot/grub/grub.cfg
```

```text
#
# DO NOT EDIT THIS FILE
#
# It is automatically generated by grub-mkconfig using templates
# from /etc/grub.d and settings from /etc/default/grub
#
```

Bạn sửa ở hai chỗ:

| Chỗ | Chứa |
|---|---|
| `/etc/default/grub` (và `/etc/default/grub.d/*.cfg`) | Các thiết lập: thời gian chờ, mục mặc định, tham số kernel |
| `/etc/grub.d/` | Các script sinh từng phần của menu. Muốn thêm mục riêng thì viết vào `40_custom` |

```bash
grep -v '^#' /etc/default/grub | grep -v '^$'
```

```text
GRUB_DEFAULT=0
GRUB_TIMEOUT_STYLE=hidden
GRUB_TIMEOUT=0
GRUB_DISTRIBUTOR=`( . /etc/os-release; echo ${NAME:-Ubuntu} ) 2>/dev/null || echo Ubuntu`
GRUB_CMDLINE_LINUX_DEFAULT="quiet splash"
GRUB_CMDLINE_LINUX=""
```

| Dòng | Ý nghĩa |
|---|---|
| `GRUB_DEFAULT=0` | Mục mặc định: mục đầu tiên. `saved` là nhớ lần chọn trước |
| `GRUB_TIMEOUT_STYLE=hidden` | Ẩn menu. Bấm giữ `Shift` (BIOS) hoặc `Esc` (UEFI) lúc khởi động để hiện menu. `menu` là luôn hiện |
| `GRUB_TIMEOUT=0` | Số giây chờ trước khi khởi động mục mặc định |
| `GRUB_CMDLINE_LINUX_DEFAULT` | Tham số kernel cho mục khởi động bình thường |
| `GRUB_CMDLINE_LINUX` | Tham số kernel cho **mọi** mục, kể cả chế độ khôi phục |

Cloud image của Ubuntu ghi đè thêm trong `/etc/default/grub.d/50-cloudimg-settings.cfg` (ví dụ `console=ttyS0` để xuất màn hình ra cổng serial của máy ảo).

### Sửa và sinh lại cấu hình

Ví dụ hiện menu 5 giây:

```bash
sudo cp /etc/default/grub /etc/default/grub.bak
sudo sed -i 's/^GRUB_TIMEOUT=.*/GRUB_TIMEOUT=5/' /etc/default/grub
sudo update-grub
```

```text
Sourcing file `/etc/default/grub'
Sourcing file `/etc/default/grub.d/50-cloudimg-settings.cfg'
Generating grub configuration file ...
Found linux image: /boot/vmlinuz-6.8.0-147-generic
Found initrd image: /boot/initrd.img-6.8.0-147-generic
...
done
```

| Lệnh | Làm gì |
|---|---|
| `update-grub` | Sinh lại `/boot/grub/grub.cfg` (Ubuntu, Debian). Thực chất là `grub-mkconfig -o /boot/grub/grub.cfg` |
| `grub2-mkconfig -o /boot/grub2/grub.cfg` | Tương đương trên RHEL/Rocky (đường dẫn có chữ `grub2`) |

(Trên cloud image, `50-cloudimg-settings.cfg` đặt lại `GRUB_TIMEOUT=0` vì được đọc sau. Muốn đổi thật thì sửa file đó.)

## Menu và tham số kernel

Các mục trong menu:

```bash
sudo grep -E "^\s*(menuentry|submenu) " /boot/grub/grub.cfg | cut -c1-70
```

```text
menuentry 'Ubuntu' --class ubuntu --class gnu-linux --class gnu --clas
submenu 'Advanced options for Ubuntu' $menuentry_id_option 'gnulinux-a
	menuentry 'Ubuntu, with Linux 6.8.0-147-generic' --class ubuntu --cla
	menuentry 'Ubuntu, with Linux 6.8.0-147-generic (recovery mode)' --cl
```

`Advanced options` chứa từng phiên bản kernel và **chế độ khôi phục** (recovery mode) của nó.

Tham số kernel máy đang dùng:

```bash
cat /proc/cmdline
```

```text
BOOT_IMAGE=/vmlinuz-6.8.0-147-generic root=LABEL=cloudimg-rootfs ro console=tty1 console=ttyS0
```

| Tham số | Ý nghĩa |
|---|---|
| `BOOT_IMAGE=` | Kernel được nạp |
| `root=LABEL=cloudimg-rootfs` | Ổ gốc (`/`) ở đâu |
| `ro` | Gắn ổ gốc chỉ đọc lúc đầu (để fsck), systemd gắn lại đọc ghi sau |
| `console=` | Thông báo khởi động in ra đâu |
| `quiet`, `splash` | Ẩn bớt thông báo, hiện màn hình chờ |
| `systemd.unit=rescue.target` | Khởi động vào chế độ cứu hộ |
| `fsck.mode=force` | Ép kiểm tra filesystem khi khởi động |

### Sửa tạm ở menu GRUB

Khi máy không khởi động được, ở menu GRUB:

| Phím | Làm gì |
|---|---|
| `↑` `↓` | Chọn mục |
| `e` | Sửa mục đang chọn. Tìm dòng bắt đầu bằng `linux`, thêm hoặc bớt tham số ở cuối dòng |
| `Ctrl+X` hoặc `F10` | Khởi động với nội dung vừa sửa. **Chỉ áp dụng lần này**, không lưu |
| `c` | Mở dòng lệnh GRUB (nâng cao) |
| `Esc` | Quay lại menu |

## Cài lại GRUB

Khi GRUB bị hỏng (hiện dấu nhắc `grub>` hoặc `grub rescue>`), bị Windows ghi đè, hoặc chuyển hệ thống sang ổ mới, cần ghi lại GRUB. Thường làm từ một USB cài Ubuntu ở chế độ "Try Ubuntu", gắn ổ hệ thống vào rồi `chroot` vào đó.

| Máy | Lệnh |
|---|---|
| BIOS | `sudo grub-install /dev/vda` (ghi vào **ổ**, không phải phân vùng) rồi `sudo update-grub` |
| UEFI | `sudo grub-install` (ghi file `.efi` vào `/boot/efi`) rồi `sudo update-grub` |

| | `update-grub` | `grub-install` |
|---|---|---|
| Làm gì | Sinh lại file cấu hình menu | Ghi chương trình GRUB vào vùng khởi động |
| Khi nào | Sau khi sửa `/etc/default/grub` | Ổ mới, GRUB hỏng |

Trên máy UEFI, xem các mục khởi động mà firmware biết: `sudo efibootmgr -v`.

## Thực hành

Trên máy ảo (VirtualBox hoặc Multipass). Chép bản dự phòng trước.

1. Máy khởi động bằng BIOS hay UEFI? Có những kernel nào trong `/boot`? Đang chạy kernel nào?

   <details>
   <summary>Xem đáp án</summary>

   ```bash
   [ -d /sys/firmware/efi ] && echo UEFI || echo BIOS
   ls /boot/vmlinuz-*
   uname -r
   ```

   </details>

2. Cho menu GRUB luôn hiện 10 giây. Sinh lại cấu hình, khởi động lại để xem menu (trên VirtualBox nhìn được màn hình). Rồi trả lại như cũ.

   <details>
   <summary>Xem đáp án</summary>

   ```bash
   sudo cp /etc/default/grub /etc/default/grub.bak
   sudo sed -i 's/^GRUB_TIMEOUT_STYLE=.*/GRUB_TIMEOUT_STYLE=menu/; s/^GRUB_TIMEOUT=.*/GRUB_TIMEOUT=10/' /etc/default/grub
   grep -E 'TIMEOUT' /etc/default/grub /etc/default/grub.d/*.cfg
   sudo update-grub
   sudo reboot
   ```

   Nếu file trong `/etc/default/grub.d/` cũng đặt `GRUB_TIMEOUT`, giá trị ở đó thắng (được đọc sau). Trả lại: `sudo cp /etc/default/grub.bak /etc/default/grub && sudo update-grub`.

   </details>

3. Ở menu GRUB, bấm `e`, thêm `systemd.unit=rescue.target` vào cuối dòng `linux`, `Ctrl+X`. Bạn vào chế độ nào? Kiểm tra bằng `systemctl get-default` và `systemctl list-units --type=target`, rồi `reboot`.

## Tóm tắt

| Việc | Lệnh / file |
|---|---|
| BIOS hay UEFI | `[ -d /sys/firmware/efi ] && echo UEFI` |
| Kernel và initramfs | `/boot/vmlinuz-*`, `/boot/initrd.img-*` |
| Thiết lập GRUB | `/etc/default/grub` (không sửa `grub.cfg`) |
| Sinh lại cấu hình | `sudo update-grub` (RHEL: `grub2-mkconfig -o ...`) |
| Tham số kernel đang dùng | `cat /proc/cmdline` |
| Sửa tạm ở menu | `e` → sửa dòng `linux` → `Ctrl+X` |
| Ghi lại GRUB vào ổ | `sudo grub-install /dev/vda` (BIOS) |
| Tạo lại initramfs | `sudo update-initramfs -u` |
